# study-notes

공부용 저장소입니다. 실험 코드, 학습 메모, 연습 문제 풀이를 자유롭게 기록합니다.

## 구조 제안

```
study-notes/
├── notes/        # 주제별 학습 메모 (Markdown)
├── exercises/    # 연습 코드와 풀이
└── README.md
```

주제가 늘어나면 `notes/` 아래에 폴더를 나눕니다. 예: `notes/shopify-liquid/`, `notes/javascript/`.

## 기록 방식

- 메모 파일 하나에 주제 하나를 다룹니다.
- 파일 맨 위에 날짜와 참고한 자료 링크를 적습니다.
- 실험 코드는 실행 방법을 함께 적어 둡니다.
